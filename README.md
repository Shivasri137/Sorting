# 🔍 Shiva's Sorting Visualizer (Python + Tkinter)

A **Sorting Algorithm Visualizer** built using **Python, Tkinter, Matplotlib, and Pygame**.  
This application helps students understand sorting algorithms visually with **animated bar charts**, **step-by-step explanation logs**, and **algorithm theory** built inside the GUI.

---

## ✨ Features

✅ Visualize sorting using animated bar graphs  
✅ Step-by-step explanation log (comparisons, swaps, merges)  
✅ Built-in theory for each algorithm  
✅ Select number of bars (10 to 100)  
✅ Sorting swap sound effects using Pygame  
✅ Multi-algorithm support in one interface  

---

## 📌 Algorithms Included

- Bubble Sort  
- Merge Sort  
- Quick Sort  
- Heap Sort  

---

## 🛠️ Tech Stack

- **Python**
- **Tkinter** (GUI)
- **Matplotlib** (Visualization)
- **Threading** (Smooth sorting animation without freezing UI)
- **Pygame** (Sound effects)

---

## 📷 Preview

📌 Bars represent values.  
Highlighted bars show comparisons/swaps during the sorting process.  
Text log explains each step in real-time.
